# Scene Composition

## Philosophy

Scenes should explain,

not decorate.

---

# Composition Layers

Foreground

↓

Primary Object

↓

Supporting Objects

↓

Background

---

# Layout Principles

Rule of Thirds

Golden Ratio

Negative Space

Visual Balance

Eye Flow

---

# Focus

Only ONE dominant object.

Everything else supports it.

---

# Relationships

Always visualize

Cause → Effect

Input → Output

Hierarchy

Dependencies

Connections

---

# Camera Framing

Leave breathing room.

Avoid cropped educational objects.

---

# White Space

White space improves understanding.

Never fill every corner.

---

# Forbidden

❌ Crowded scenes

❌ Floating unrelated objects

❌ Random spacing

❌ Decorative clutter

---

# Success Criteria

The student should immediately know

"What should I look at first?"
