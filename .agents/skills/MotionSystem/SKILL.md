# Motion System

## Mission

Motion exists to guide attention.

Never animate merely for decoration.

Every animation must improve understanding.

---

# Motion Philosophy

Motion should feel

Natural

Predictable

Physical

Elegant

Responsive

Never robotic.

---

# Motion Principles

Objects have mass.

Objects have momentum.

Objects accelerate.

Objects decelerate.

Objects never teleport.

---

# Preferred Motion Curves

ease-out

ease-in-out

spring

cubic-bezier

Avoid linear.

---

# Duration Guide

Micro Feedback

100–180ms

Buttons

180–250ms

Cards

250–350ms

Panels

350–500ms

Scene Transition

500–800ms

Never exceed

1000ms

---

# Educational Motion

Motion should

Reveal

Explain

Guide

Focus

Never distract.

---

# Animation Priorities

Focus Movement

↓

Object Relationship

↓

Visual Feedback

↓

Decorative Motion

---

# Forbidden

❌ Infinite bouncing

❌ Flashing

❌ Random movement

❌ Linear interpolation

❌ Sudden appearance

❌ Teleporting UI

---

# Success Criteria

Students should never consciously notice animations.

They should simply feel that everything is fluid.
