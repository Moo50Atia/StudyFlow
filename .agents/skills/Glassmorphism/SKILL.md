# Glassmorphism Design System

## Objective

All floating interfaces should feel lightweight,
premium,
and layered above the educational canvas.

---

# Background

Canvas

↓

Gradient

↓

Glass Panels

↓

Floating Controls

↓

Dialogs

---

# Panel Rules

Use

backdrop-blur-xl

Semi-transparent surfaces

Rounded corners (16–24px)

Soft borders

Subtle shadows

---

# Opacity

Dark Mode

8–15%

Light Mode

50–70%

Never use solid panels.

---

# Borders

border-white/20

Never pure white.

---

# Shadows

Soft shadows only.

Never heavy black shadows.

Prefer layered shadows.

---

# Blur

Minimum

blur-lg

Preferred

blur-xl

Maximum

blur-2xl
