# UI Consistency Standard

## Objective

Every generated page should feel like part of the same product.

---

# Spacing Scale

4

8

12

16

24

32

48

64

Never invent arbitrary spacing.

---

# Border Radius

Buttons

14

Cards

20

Dialogs

24

Badges

999

---

# Icons

Use one icon family only.

Lucide preferred.

Never mix icon packs.

---

# Buttons

Primary

Filled

Secondary

Outlined

Danger

Red

Ghost

Transparent

Maximum four button styles.

---

# Cards

One elevation style.

One border style.

One spacing system.

---

# Inputs

Equal height.

Equal padding.

Equal focus behavior.

---

# Animation Timing

Fast

150ms

Normal

250ms

Slow

400ms

Never exceed

600ms

---

# Grid

Use consistent 12-column layouts.

Maintain equal gutters.

---

# Forbidden

Mixed corner radius

Mixed shadows

Different button sizes

Random spacing

Random typography

---

# Success Criteria

If two screens are shown side by side,

they should clearly belong to the same design language.
