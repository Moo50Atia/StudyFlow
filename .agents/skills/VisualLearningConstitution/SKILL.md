# Visual Learning Constitution

## Mission

Every generated interface MUST improve understanding.

The objective is NOT to create beautiful graphics.

The objective is to transform difficult concepts into intuitive visual understanding.

Beauty always serves learning.

Never the opposite.

---

# Core Principles

## Principle 1 — Understanding Before Decoration

Every visual element must have educational value.

If an object does not help explain the concept,
it must not exist.

---

## Principle 2 — One Concept at a Time

Each screen should teach ONE primary concept.

Avoid cognitive overload.

Progressive disclosure is mandatory.

---

## Principle 3 — Motion Has Meaning

Animations must guide attention.

Never animate purely for aesthetics.

Every movement should answer:

"What is the learner supposed to notice?"

---

## Principle 4 — Interactive Learning

Students should discover concepts through interaction.

Prefer:

Dragging

Rotating

Exploring

Simulating

Predicting

instead of passive reading.

---

## Principle 5 — Visual Hierarchy

Always establish

Primary Focus

↓

Secondary Context

↓

Supporting Information

↓

Decorative Elements

---

## Principle 6 — Reduce Cognitive Load

Large paragraphs are forbidden.

Prefer

Illustrations

Animations

Diagrams

Interactive Objects

Short Explanations

---

## Principle 7 — Explain Relationships

Instead of listing facts,

show relationships.

Examples

Cause → Effect

Input → Process → Output

Network Topology

Memory Layout

Signal Flow

Data Flow

Algorithm Steps

---

## Principle 8 — Students Learn By Seeing

Whenever possible,

replace text with visualization.

---

# Forbidden Patterns

❌ Long paragraphs

❌ Random icons

❌ Decorative animations

❌ Flashing colors

❌ Information overload

❌ Empty whitespace without purpose

❌ Duplicate explanations

❌ Unnecessary 3D objects

---

# Success Criteria

Every generated page must answer:

"What became easier to understand after seeing this?"

If nothing,

the page has failed.

---

# Agent Checklist

Before generating any scene ask:

✓ Does this teach one concept?

✓ Is every animation meaningful?

✓ Can the student understand without reading everything?

✓ Does interaction reinforce learning?

✓ Is the UI secondary to the content?

Only then generate the scene.
