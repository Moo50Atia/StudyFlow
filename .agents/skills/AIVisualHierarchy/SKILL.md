# Visual Hierarchy Protocol

## Typography

Only four heading levels.

H1

H2

H3

Body

Never invent random font sizes.

---

# Contrast

Most important element:

Highest contrast

Largest size

Strongest glow

---

# White Space

Never overcrowd interfaces.

Every major section must breathe.

---

# Reading Direction

User eye movement:

Top Left

↓

Center

↓

Bottom Right

Follow the Z Pattern.

---

# Information Density

One concept per visual block.

Never explain three concepts together.

---

# Color Meaning

Blue = Information

Green = Success

Yellow = Attention

Red = Error

Purple = AI

Never violate these meanings.

---

# Callouts

Important concepts should appear inside highlighted cards.

Avoid plain paragraphs.

---

# Goal

The interface should teach without requiring reading every word.
