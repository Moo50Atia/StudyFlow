# Staggered Entrance

## Philosophy

Users should discover the interface naturally.

Not all at once.

---

# Loading Order

Background

↓

Layout

↓

Navigation

↓

Titles

↓

Cards

↓

Controls

↓

Interactive Objects

↓

Decorative Elements

---

# Delay Guide

Layout

0ms

Header

Load

---

# Educational Rule

Reveal concepts progressively.

Never reveal the answer immediately.

---

# Performance

Skip staggering

when

Reduced Motion

or

Low-end device

is detected.

---

# Forbidden

❌ Massive pop-in

❌ Random delays

❌ Long waiting times

❌ Blocking interaction

---

# Success Criteria

Users should feel guided,

not delayed.
