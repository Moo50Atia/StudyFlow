name: AccessibilityFirst
description: Enforces WCAG-compliant accessible interfaces for all generated educational content.
---

# Accessibility Protocol

## Keyboard

Everything must work using keyboard only.

No mouse dependency.

---

# Focus

Visible focus rings are mandatory.

Never remove outline.

---

# Contrast Ratio

Minimum WCAG AA.

Never use low contrast text.

---

# Screen Readers

Every button requires:

aria-label

Every image requires:

alt text

Every canvas requires:

description.

---

# Motion

Respect:

prefers-reduced-motion

Disable animations automatically.

---

# Font Sizes

Never use text below 14px.

Educational content:

16px+

---

# Errors

Never rely on color alone.

Use:

Icons

Labels

Messages

---

# Goal

Every student should be able to learn regardless of physical limitations.
