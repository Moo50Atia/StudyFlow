# Narrative Learning Flow Protocol

## Objective

Every generated lesson must feel like a guided journey.

The learner should never feel lost.

Every interaction must answer:

> "Why am I seeing this now?"

---

# Learning Sequence

Always build pages using this order:

1. Hook
2. Context
3. Visualization
4. Exploration
5. Experiment
6. Reflection
7. Practice
8. Assessment
9. Summary

Never skip steps.

---

# Progressive Disclosure

Never reveal everything immediately.

Instead:

Step 1
↓

User explores

↓

More information appears

↓

User interacts again

↓

Advanced layer appears

---

# Storytelling

Every visualization should tell a story.

Instead of

"This is an electric field"

Prefer

"Imagine placing a positive charge here..."

then animate the consequences.

---

# Scene Progression

Each scene should naturally lead to the next one.

Avoid isolated pages.

---

# Curiosity

Frequently create moments where the learner wants to continue.

Examples:

"What happens if..."

"Try increasing..."

"Can you predict..."

---

# Educational Goal

The learner should remember the journey,
not individual UI components.
