# Typography System

## Objective

Typography should reduce reading effort.

---

# Font Preference

Inter

Geist

IBM Plex Sans

Noto Sans

---

# Hierarchy

Display

48–64px

Heading

32–40px

Section

24–28px

Body

16–18px

Caption

14px

Label

12px

---

# Line Length

Maximum

75 characters

---

# Alignment

Prefer Left

RTL pages

Prefer Right

Never justify text.

---

# Spacing

Heading

1.2

Body

1.6

Lists

1.5

---

# Rules

Never ALL CAPS.

Avoid italics.

Bold only for emphasis.

Maximum 2 font weights per screen.

---

# Forbidden

Tiny fonts

Dense paragraphs

Centered paragraphs

Decorative fonts

---

# Success Criteria

A learner should scan the page in less than five seconds.
